# Security Policy

## Reporting a Vulnerability

Please do not open a public GitHub issue for undisclosed security problems.
Report vulnerabilities to the maintainers through a private channel first.

Include:

- A clear description of the issue.
- Steps to reproduce it.
- Affected package or app path.
- Any suggested fix or mitigation, if known.

Maintainers should acknowledge valid reports as soon as practical and coordinate
public disclosure after a fix is available.
