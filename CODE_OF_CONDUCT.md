# Code of Conduct

## Our Pledge

We want this project to be welcoming, useful, and respectful for everyone.
Contributors are expected to communicate with care, assume good intent, and keep
discussions focused on improving the project.

## Expected Behavior

- Be respectful of differing experience levels and viewpoints.
- Give constructive feedback.
- Keep issues and pull requests on topic.
- Credit ideas and work from others where appropriate.

## Unacceptable Behavior

- Harassment, threats, insults, or personal attacks.
- Discriminatory language or behavior.
- Publishing private information without permission.
- Repeated off-topic or disruptive comments.

## Enforcement

Project maintainers may remove comments, close issues, or block contributors who
do not follow this code of conduct. If you see behavior that makes the project
less welcoming, please report it to the maintainers through an appropriate
private channel.
